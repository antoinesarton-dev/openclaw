# Fiche 29 — Plan d'approche de 10 micro-créateurs 🛠️

- **Type :** 🛠️ Pratique · **Nature :** ⚡ (calé sur 2026) · **Durée :** ~1 h · **Prérequis :** Fiche 28
- **Terrain :** Boutique canicule

## L'exercice

Construis un **plan d'outreach réel** pour recruter des micro-créateurs pour le produit canicule :
une short-list, un template de message, une offre, et un brief.

### Livrable 1 — La short-list (10 profils, critères)

Un tableau de 10 cibles (réelles ou réalistes si tu ne veux pas fouiller les vrais comptes) :

| # | Créateur / niche | Taille | Pourquoi lui (fit avec canicule) | Signal d'engagement réel à vérifier |
|---|---|---|---|---|

Le point noté n'est pas d'avoir de vrais handles, c'est ta **méthode de sélection** : niche pertinente,
engagement réel (commentaires), audience FR, cohérence avec le produit.

### Livrable 2 — Le message d'approche (template)

Un message court et personnalisable. Il doit : montrer que tu connais leur contenu (1 détail précis),
proposer une valeur claire, être bref, et donner un *next step* simple. Interdits : le copier-coller
générique « Bonjour, super compte ! », la demande floue.

### Livrable 3 — L'offre + le brief

- **L'offre** : ce que tu proposes (produit offert / fixe / affiliation avec code traçable) et
  **pourquoi elle est réaliste pour ta marge** (fiche 33).
- **Le brief** : l'angle et le problème à montrer (PAS), les 3 incontournables (hook rapide, démo,
  CTA), la liberté laissée sur la voix, et la **mention des droits d'usage** + transparence #ad.

## Grille de notation (/20)

| Axe | Ce que je regarde |
|---|---|
| **Spécificité** | Critères de sélection concrets ; message avec une vraie personnalisation |
| **Mécanique** | Micro bien ciblés, engagement > followers, brief = angle pas script, droits + code traçable |
| **Clarté** | Message court avec un next step évident ; offre lisible |
| **Adéquation** | Réaliste pour une marge dropshipping ; transparence légale respectée |

Colle les 3 livrables dans `journal-de-progression.md`. Je note et je réécris ton message d'approche
s'il sonne « copier-coller » (la cause n°1 d'échec de l'outreach).

## Anti-triche

- Le message doit contenir **une vraie personnalisation** possible (un champ « [détail que j'ai
  remarqué sur ton compte] » ne suffit pas si tu ne montres pas *comment* tu le remplis).
- L'offre doit passer le test de la marge : si tu ne peux pas te payer 5 de ces deals, revois-la.

## Explique-moi (Feynman)

Lis ton message d'approche comme si tu étais le créateur qui en reçoit 20 par jour. Est-ce que tu
répondrais ? Qu'est-ce qui te ferait *supprimer* le tien ? Corrige ça.

## Cartes de rappel → `revision-espacee.md`

- Sélection : niche + engagement réel (commentaires) + fit produit, pas les followers.
- Message : personnalisation réelle + valeur claire + next step simple ; jamais générique.
- Offre testée contre la marge ; code promo traçable pour mesurer (fiche 30) ; droits + #ad.
